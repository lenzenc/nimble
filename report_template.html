nimble

A decision model doesn't write text. It reads a state, answers typed questions with probabilities, and does it in a single pass. Below: what each question type returns, on realistic use cases.

The three question types

noul Is it true?

A probability that a statement holds. Not a bool: 0.13 and 0.52 mean different things.

{ "noul": 0.9993 }

choice Which one?

Pick one option from plain-English criteria. Returns every option's probability and a confidence.

{ "choice": "billing", "probabilities": {…}, "confidence": 0.94 }

score How much?

Position on an ordered scale: a probability-weighted level index you can rank and threshold.

{ "score": 2.4, "legend": {…}, "probabilities": {…} }
